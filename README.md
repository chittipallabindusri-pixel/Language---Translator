# 🌐 Language Translator

## About Project
Language Translator is a simple web application that helps users translate text from one language to another.

## Features
- English to Telugu Translation
- English to Hindi Translation
- Telugu to English Translation
- Copy Translated Text
- User-Friendly Interface

## Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API
